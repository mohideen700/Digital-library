ℹ️ About

Digital Library Management System

The Digital Library Management System is a web-based application designed to simplify library operations.


The system provides modules for managing books, members, issuing books, returning books and generating library reports.


This project uses HTML, CSS and JavaScript with Local Storage for storing application data.
